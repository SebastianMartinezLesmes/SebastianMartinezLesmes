# Bugfix Requirements Document

## Introduction

The GitHub profile README for SebastianMartinezLesmes uses several third-party widgets and services that have become unreliable or produce visual errors. Specifically, services hosted on `demolab.com` suffer from frequent downtime, the streak stats widget is consistently unstable, the tech stack section uses text-based shields.io badges instead of modern visual icons, and the main GitHub stats card is missing entirely. This bugfix replaces all unstable services with proven alternatives, adds the missing stats card, and modernizes the tech stack visualization using `skillicons.dev`.

---

## Bug Analysis

### Current Behavior (Defect)

1.1 WHEN a visitor loads the README THEN the system displays a broken or missing streak stats image because `streak-stats.demolab.com` is unavailable or rate-limited

1.2 WHEN a visitor loads the README THEN the system displays a broken or missing typing animation because `readme-typing-svg.demolab.com` is unavailable due to demolab service instability

1.3 WHEN a visitor loads the README THEN the system renders the Tech Stack section with small text-based shields.io badges that are visually inconsistent and harder to scan than icon-based alternatives

1.4 WHEN a visitor loads the README THEN the system shows only "Streak Stats" and "Top Languages" in the GitHub Stats section, omitting the main stats card (commits, PRs, issues, stars)

1.5 WHEN a visitor loads the README THEN the system may display a broken trophies image because `github-profile-trophy.vercel.app` is called without a reliable theme parameter, causing inconsistent rendering

1.6 WHEN a visitor loads the README in dark mode THEN the system shows the Ocean GIF snake variant which is a heavy animated GIF that increases page load time unnecessarily

### Expected Behavior (Correct)

2.1 WHEN a visitor loads the README THEN the system SHALL display a profile visitor counter using `komarev.com/ghpvc` (a stable, widely-used service) as a replacement for the unstable streak stats widget

2.2 WHEN a visitor loads the README THEN the system SHALL display the typing animation using a self-hosted or reliably available service, OR replace it with a static but visually appealing header that does not depend on demolab availability

2.3 WHEN a visitor loads the README THEN the system SHALL render the Tech Stack section using `skillicons.dev` SVG icon rows, providing a modern, visual, and consistently available icon set

2.4 WHEN a visitor loads the README THEN the system SHALL display three GitHub stats widgets: the main stats card (commits, PRs, issues, stars), and the top languages card, all from `github-readme-stats.vercel.app` with correct parameters (`show_icons=true`, `theme=tokyonight`, `hide_border=true`, `include_all_commits=true`, `count_private=true`)

2.5 WHEN a visitor loads the README THEN the system SHALL display trophies from `github-profile-trophy.vercel.app` with explicit `theme=tokyonight`, `no-frame=true`, and `no-bg=true` parameters for stable and consistent rendering

2.6 WHEN a visitor loads the README THEN the system SHALL show only the SVG-based snake animation (dark and light variants) without the heavy Ocean GIF variant, reducing page weight

### Unchanged Behavior (Regression Prevention)

3.1 WHEN a visitor loads the README THEN the system SHALL CONTINUE TO display the About Me section with the same personal information and professional summary

3.2 WHEN a visitor loads the README THEN the system SHALL CONTINUE TO show social/professional links (LinkedIn, Pinterest, GitHub) as clickable badge buttons

3.3 WHEN a visitor loads the README THEN the system SHALL CONTINUE TO show the Recent Repositories section with the same auto-updated table (managed by the existing GitHub Actions workflow)

3.4 WHEN a visitor loads the README THEN the system SHALL CONTINUE TO display the GitHub contribution snake animation using the SVG outputs already generated by the existing `contribution-snake.yml` workflow

3.5 WHEN a visitor loads the README THEN the system SHALL CONTINUE TO show the Free Dev Resources link pointing to `./pages.md`

3.6 WHEN a visitor loads the README THEN the system SHALL CONTINUE TO display the content in English

## Bug Condition Derivation

**Bug Condition Function** — identifies inputs that trigger visual breakage:

```pascal
FUNCTION isBugCondition(X)
  INPUT: X of type ReadmeWidget
  OUTPUT: boolean

  RETURN (X.service CONTAINS "demolab.com")
      OR (X.widgetType = "streak-stats")
      OR (X.widgetType = "tech-stack-badges" AND X.format = "shields-text")
      OR (X.widgetType = "stats-section" AND X.cards < 2)
      OR (X.widgetType = "trophy" AND X.theme = UNSET)
      OR (X.widgetType = "snake-gif-ocean")
END FUNCTION
```

**Property: Fix Checking**

```pascal
FOR ALL X WHERE isBugCondition(X) DO
  result ← renderWidget'(X)
  ASSERT result.loads = true
       AND result.service = STABLE_ALTERNATIVE
       AND result.visuallyCorrect = true
END FOR
```

**Property: Preservation Checking**

```pascal
FOR ALL X WHERE NOT isBugCondition(X) DO
  ASSERT renderWidget(X) = renderWidget'(X)
END FOR
```
